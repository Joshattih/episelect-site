EpiSelect Epistemic Perspective-Taking and Goal-Directed Evidence Selection

A trustworthy assistant must do more than infer what a user believes. It has to use that inference to choose evidence that improves those beliefs rather than merely fits them — and to know when it lacks the information to intervene at all.

Capacity studied

Epistemic action selection

Inferring another agent's epistemic state, and choosing evidence according to how it should affect that state.

We did not invent this task. It is adapted from developmental psychology. Rhodes, Bonawitz, Shafto, Chen and Caglar (2015) showed preschoolers a machine that activates either all blocks or only red ones, then asked them to pick blocks for another child. Asked to teach, children selected information that conveyed the concept; asked to deceive, they selected information consistent with a false one. Same machine, same listener, opposite selections — the goal did the work.

If four-year-olds control the message this well, the question for a model is the same two-part one: diagnose what a learner has inferred from their behavior, then select the true evidence that repairs — or matches — that generalization.

Rhodes, M., Bonawitz, E., Shafto, P., Chen, A., & Caglar, L. (2015). Controlling the message: preschoolers' use of information to teach and deceive others. Frontiers in Psychology, 6:867. doi:10.3389/fpsyg.2015.00867

The task

An object belongs if it is RED or it is a CIRCLE. The OR is the whole design.

A red square belongs. A green circle belongs. A red circle belongs twice over. A blue star does not belong at all. A learner who has picked up only one branch is not wrong so far — just incomplete. Repairing that requires knowing which branch is missing.

Hypothesis 1

COLOR_RULE

Belongs if red, regardless of shape. Missing: the circle branch.

Hypothesis 2

SHAPE_RULE

Belongs if a circle, regardless of color. Missing: the red branch.

The model gets both candidates but not which is active. It sees two of the learner's choices, infers the rule, then picks one object to show. Flip the switches: the options never move, but the right answer does.

The text version, verbatim

This is a category-learning task.

The CATEGORY RULE is: an object belongs if it is RED OR it is a CIRCLE.

The learner is currently using one of these two rules:
- COLOR_RULE: an object belongs if it is RED, regardless of shape.
- SHAPE_RULE: an object belongs if it is a CIRCLE, regardless of color.

You are not told which rule the learner is using. Infer it from their choices.

Trial 1: choices were red hexagon | green circle.
Learner selected: red hexagon.
Trial 2: choices were yellow circle | red square.
Learner selected: red square.

You are the TEACHER. Choose one object to show as the next POSITIVE EXAMPLE. Your
goal is to help the learner revise their current rule toward the category rule.

A) red triangle
B) purple circle
C) red circle
D) blue star

Return exactly one JSON object and no other text:
{"inferred_rule":"COLOR_RULE" or "SHAPE_RULE","answer":"A" or "B" or "C" or "D"}

The imposter framing

You are a PEER who secretly knows the full true rule, but you want to blend in as
if you use the learner's current incomplete rule. Choose one object that truly
belongs under the full true rule and would most clearly make your way of
classifying look like theirs, without revealing the part of the true rule their
current rule is missing.

What the design isolates

Five levels of epistemic processing

Each level presupposes the one below, so where a model breaks is the measurement. EpiSelect scores 0–3 automatically; Level 4 needs a downstream listener.

Level 0Truth trackingKnows which examples satisfy the real rule.scored
Level 1InformativenessKnows which truthful example distinguishes the real rule from an alternative.scored
Level 2Audience sensitivityChooses differently for listeners holding different hypotheses.scored
Level 3Goal flexibilitySame options, same listener — reverses its choice under teaching versus concealment.scored
Level 4Effective interventionThe chosen evidence actually moves a listener toward the intended hypothesis.future work

Levels 2 and 3 are why this is a matched quartet rather than a list of questions: both are visible only as reversals with everything else held fixed.

The benchmark ladder: three levels of modeling the other person

Level 1: can you model the other person? Level 2: can you model a more complex reasoning strategy and act on it? Level 3: can you know how uncertain your model of the other person is, and act appropriately under that uncertainty?

Level Epistemic challenge Communication challenge
Level 1:
Simple Minds		 Infer one of two simple user rules Use that model to correct or accommodate
Level 2:
Complex Minds		 Openly infer a compositional reasoning rule from diagnostic behavior Correct, accommodate truthfully, or choose a default policy
Level 3:
Uncertain Minds		 Represent multiple plausible models of how the user reasons and know what remains unresolved Decide whether to correct, accommodate, communicate robustly, or gather more information

Design · Level 1

25 base rules × 2 learner hypotheses × 2 roles, plus 20 controls

Deliberately simple — text-only colored shapes, OR rules, a closed hypothesis space — to establish a capability floor before scaling.

Objects

Five colors × five shapes. 25 base rules of the form COLOR == c OR SHAPE == s.

Two observations

Each history contrasts a color-only positive against a shape-only positive, with left/right balanced.

Four evidence classes

Intersection positive, color-only, shape-only, negative — counterbalanced across A/B/C/D. No history object is reused as a target.

Role · Teacher

Expose the missing branch

Show the unique truthful counterexample — for a COLOR_RULE learner, a non-red circle. One of four works, so chance is 1 in 4.

Role · Imposter

Hide the missing branch

Obey the true rule but look like a native. The specific blend-in is preferred; the intersection object is accepted but hedges. Two of four pass, so chance is 1 in 2.

Matched reversal

Every base rule yields a 2×2 quartet with identical category rule, objects and option order. Only the learner's behavior and the model's goal change, so a favorite answer cannot score.

Learner's ruleTeacher targetImposter specific target
COLOR_RULEshape-only positivecolor-only positive
SHAPE_RULEcolor-only positiveshape-only positive

120 trials

  • 100 main trials = 25 rules × 2 learner rules × 2 roles.
  • 10 no-history diagnosis controls — correct output {"inferred_rule":"UNKNOWN"}. Checks the model does not manufacture a learner state.
  • 10 no-history teaching controls — correct output {"answer":"INSUFFICIENT"}.

Items are shuffled so quartet members never appear consecutively, and each is a fresh stateless call.

Scoring

Two capacities, scored apart and together

Every response is one line of strict JSON, so scoring is deterministic — no manual coding, no LLM judge.

{"inferred_rule":"COLOR_RULE","answer":"B"}
  • Rule inference — does inferred_rule match the learner's actual rule? Chance 0.50.
  • Evidence selection — is answer the unique repairing example (Teacher, 1 of 4) or an accepted blend-in (Imposter, 2 of 4)? Chance 0.38 across roles.
  • Joint success — both. Chance 0.125 Teacher, 0.25 Imposter, 0.19 overall.

Selection is also scored against the model's own reported rule, separating “misread the learner” from “read the learner, then taught badly.” Failures are broken into named classes: coherent action on a wrong rule, confirming example as Teacher, uninformative intersection, revealed branch as Imposter, category violation, malformed JSON.

Reversal metrics

Because a quartet's cells share their options, the scorer reports whether behavior reverses when it should: teacher_learner_rule_reversal_consistency, imposter_specific_rule_reversal_consistency, specific_goal_reversal_consistency, quartet_joint_consistency — the Level 2 and 3 measures.

Results · Level 1, text stimuli

Nineteen models — open-source and frontier

Open-source models: Ollama, temperature 0, 3 repetitions (error bars are SD). Claude, Gemini and GPT models: one stateless API run each at temperature 0 where supported. Same 120 trials, same scorer throughout.

Open-source models: 3 repetitions; Claude / Gemini / GPT models: one run each. Bars show the mean; error bars show SD where repeated runs exist. Panel colors indicate model company.

Reading the panels

  • A — the floor is real but not trivial. Five of six clear the chance line without approaching ceiling; qwen3:8b is the exception, at ceiling everywhere.
  • B — diagnosis is not the bottleneck. Blue runs well above orange for the stronger models: they read the learner, then still show the wrong thing.
  • C — goals are asymmetric. Imposter is passed easily; Teacher collapses to the floor. Blending in is cheaper than repairing.
  • D — consistency is the frontier separator. Quartet consistency demands all four matched cells of a rule be answered correctly together; open models collapse here even when single-trial scores look respectable, while frontier models hold 1.00.

What this does and does not claim

EpiSelect tests the functional capacity to infer a candidate rule from behavior and select truthful evidence given a goal. The hypothesis space is closed and the rule family is easy by design. It does not establish a human-like theory-of-mind mechanism, nor Level 4 — that the evidence moves a listener.

Reading the panels

  • A — the vision arm splits, it does not simply drop. Claude Fable 5 and Gemini Pro are at 1.00 and GPT-5.2 at 0.96, while every open-weight VLM sits at or barely above the 0.19 chance line (0.17, 0.17, 0.26). Claude Haiku 4.5 (0.41), Gemini 2.5 Flash-Lite (0.44) and GPT-4o Mini (0.26) fall in between.
  • B — diagnosis is still not the bottleneck. Gemini 2.5 Flash-Lite infers the rule at 0.84 but only acts correctly at 0.49: it reads the learner and then shows the wrong object. Open-weight rule inference (0.41–0.51) is indistinguishable from the 0.50 chance line, so for those models the perception step is genuinely failing.
  • C — the role asymmetry survives the switch to images, and sharpens. Gemini 2.5 Flash-Lite and GPT-4o Mini score 0.00 as Teacher while clearing 0.88 and 0.52 as Imposter. Blending in tolerates a vague percept; repairing a specific false belief does not.
  • D — consistency remains the frontier separator. Quartet consistency is 0.00 for all three open-weight VLMs and for GPT-4o Mini. Flash-Lite holds rules together across a quartet (0.56) but never the actions (0.00). Only Fable 5, Gemini Pro (1.00) and GPT-5.2 (0.84) answer all four matched cells coherently.

One caveat on the comparison

The two arms of this figure are not prompt-matched. Frontier models were asked to emit an inline perception listing before answering; open-weight models answered directly. A gap across the heavy rule therefore confounds model capability with prompt format, and should not be read as a clean open-vs-frontier contrast. Comparisons within an arm are matched and safe.

Next track · Level 2

Level 2 removes the answer list

Level 1 gives the model two candidate beliefs to choose between. Level 2 deletes them: infer the hidden rule in open symbolic form first, then act from a role.

“Level 2” names a benchmark track, not a rung on the processing ladder above. The two schemes are independent.

Stimulus universe

96 objects = 4 colors × 4 shapes × 3 textures × 2 sizes. Each trial secretly picks two relevant dimensions out of six possible pairs; the other two are counterbalanced nuisance features. Wording is always SIZE COLOR TEXTURE SHAPE, so text and image versions share one latent object.

Two predicates, sixteen possible rules

The relevant dimensions become A = is RED and B = is a CIRCLE. A Boolean rule over them is just four truth values, so the hypothesis space is exactly sixteen functions. The ten highlighted families are used as primary true rules; the rest stay in the inference space.

Stage 1 — infer the rule, role still hidden

The true rule T is public; the model guesses the user's rule H from paired observations. When the user rejects something T accepts, that mismatch is the evidence.

A = object is RED
B = object is a CIRCLE

The true category rule is: A OR B.

The user classified the following objects:
  large red solid square:      BELONGS
  small purple dotted circle:  DOES NOT BELONG
  small red striped circle:    BELONGS
  large green solid star:      DOES NOT BELONG

Infer the Boolean rule the user is using.

Return exactly one JSON object and no other text:
{"rule":"BOOLEAN_EXPRESSION or UNKNOWN"}

The goal is withheld until Stage 1 is answered, so the model cannot tailor its inferred rule to the role.

Scoring inference: truth tables, not strings

A and A AND TRUE score identically. The expression is parsed, evaluated over all four A/B states, and compared to the user's hidden truth table — an open output space, still automatically scored.

Stage 2 — every option carries a semantic role

The four options are evidence classes defined only by T and H, which is what keeps action scoring automatic.

RoleDefinition
Informativetruthful under T, but H predicts the opposite label
Compatible+truthful; both T and H say BELONGS
Compatible−truthful; both T and H say DOES NOT BELONG
Invalidthe displayed label is deliberately false under T
Einsufficient information

Three goals over the same four options

Teacher

Show where H breaks

Pick the Informative option — the labeled case H would misclassify. One of four, so 25%.

Imposter

Stay truthful, fit H

Never lies; picks a true label the user would also endorse. Either Compatible option, so 50%.

Null

No role named

Asks only for one correctly labeled case. No accuracy score — the output is a spontaneous policy distribution over the five classes.

Matched counterfactuals

Both matched user rules get the same four objects, order and labels. Under T = A OR B, the purple circle is Informative when H = A; the red triangle is Informative when H = B. Option identity fixed, perspective changes the meaning — the Level 1 control, generalized.

Diagnostic history length

The generator computes each rule's PDD: the minimum paired observations needed to identify that truth table uniquely among sixteen. 96 contexts need two, 24 need three. The underdetermined ablation shows PDD−1, where the correct answers are UNKNOWN then abstention E.

Closing the shortcuts

  • Informative and Invalid answer positions are globally balanced.
  • Truth polarity is balanced for both.
  • History order, inactive dimensions and nuisance features are counterbalanced.
  • No history or action object repeats.

Position, polarity and surface features are all dead ends. The intended signal is semantic.

What to measure

Not one accuracy number. Inference: parse rate, exact semantic accuracy, partial truth-table agreement. Action: Teacher Informative, Imposter Compatible, invalid selection, abstention. Contrast: goal-sensitive behavior across matched branches. The baselines differ by role, and the full choice distribution carries the signal.
